# SmsPigeon 短信命令手册

SmsPigeon 的全部配置与控制均通过**短信命令**完成，语法参照 AT 命令风格。
固件全程本地运行，不连接任何远程管理服务。

## 命令语法

| 形式 | 含义 | 示例 |
|---|---|---|
| `AT+CMD?` | 查询 | `AT+ST?` |
| `AT+CMD=参数1,参数2` | 设置（参数用英文逗号分隔） | `AT+WL=ADD,13800138000` |
| `AT+CMD` | 执行 | `AT+RESET` |
| `AT+CMD=?` | 查看该命令用法 | `AT+WL=?` |
| `AT` | 链路探测（检查设备与鉴权是否正常） | `AT` |

规则：

- 命令名**大小写不敏感**（`at+st?` 与 `AT+ST?` 等价）；
- 参数保持原样（URL、密码区分大小写）；
- 参数中不可包含英文逗号（它是参数分隔符）；Webhook URL 天然不含逗号；
- 命令前后允许空白字符；
- 所有应答通过短信发回命令发送者。

## 密码模式

设置密码后，命令开头的 `AT` 替换为密码，`AT` 前缀立即失效：

```
8888+ST?          （密码为 8888 时的查询命令）
8888              （链路探测）
```

用密码前缀发不出合法命令的短信一律按普通短信转发。密码本身
**不会**改变转发行为，只影响命令识别。

## 鉴权模型

固件有三道独立门禁，**已启用的门禁必须全部通过**：

1. **初始化门禁**：未初始化的固件只接受 `AT+INIT`，其余命令一律
   静默丢弃（不回复、不转发）；
2. **白名单门禁**：白名单开启时，发送者号码必须在白名单内；
3. **密码门禁**：设置密码后，命令必须以密码开头（见上节）。

白名单与密码相互独立：

| 白名单 | 密码 | 效果 |
|---|---|---|
| 开 | 未设 | 仅白名单号码可控制 |
| 开 | 已设 | 白名单号码 + 密码前缀，两者都要满足 |
| 关 | 已设 | 任何知道密码的人可控制 |
| 关 | 未设 | **任何 AT 命令短信均可控制本机（危险）** |

号码匹配会自动归一化：`+8613800138000`、`13800138000` 视为同一号码，
白名单/转发列表中统一存储 11 位裸号码（5 位以上短号亦可）。

被拒绝的命令（未初始化、未授权）不会收到任何回复，防止探测。

## 命令总览

### AT+INIT —— 初始化（唯一免鉴权命令）

```
AT+INIT=<模块IMEI>
```

- 仅未初始化状态可用，IMEI 必须与模块实际 IMEI 完全一致；
- 发送者号码自动加入白名单；
- 已初始化的固件再次收到 INIT 只回笼统 `ERROR`（不区分 IMEI 错误
  还是已初始化，避免泄露状态）。

模块 IMEI 可从模块丝印/包装查询，也可在 Luatools 日志中查看。
初始化成功后即可用其他命令配置转发通道。

### AT —— 链路探测

发送 `AT`，收到 `OK:SmsPigeon` 表示鉴权通过、设备在线。

### AT+HELP? —— 命令列表

### AT+VER? —— 版本

### AT+ST? —— 状态总览

应答示例：

```
OK:
版本:SmsPigeon 1.0.0
模块:Air780EHV
IMEI:86xxxxxxxxxxxxx
ICCID:8986xxxxxxxxxxxxxxxx
信号:25
白名单:开(2个)
密码:未设置
通道:
 短信:开(1个目标)
 钉钉:开
 飞书:未配置
 Server酱:未配置
```

### AT+WL —— 白名单管理

| 命令 | 说明 |
|---|---|
| `AT+WL?` | 查看白名单 |
| `AT+WL=ADD,号码` | 添加（自动归一化，上限 10 个） |
| `AT+WL=DEL,号码` | 删除 |
| `AT+WL=ON` / `AT+WL=OFF` | 开/关白名单 |

安全约束：

- 白名单开启时**不可删空**（最后一个号码删不掉，防止把自己锁死），
  需先 `AT+WL=OFF`；
- 关闭白名单且未设密码时，应答会附带风险警告。

### AT+PW —— 密码管理

| 命令 | 说明 |
|---|---|
| `AT+PW=<新密码>` | 设置密码（4-16 位，不含逗号/空格，不可为 `AT`） |
| `AT+PW=` | 清除密码，恢复 AT 前缀 |

修改密码时用**旧密码**前缀发命令（如旧密码 8888：`8888+PW=6666`）。
密码仅保存在模块本地。

### AT+FWD —— 转发通道管理

`AT+FWD?` 查看所有通道状态。

通道标识：`SMS`（短信）、`DING`（钉钉）、`FS`（飞书）、`SC`（Server酱）。

通用子命令（对所有通道）：`ON` 开启、`OFF` 关闭、`CLR` 清空配置。

#### 短信通道（离线可用）

```
AT+FWD=SMS,ADD,13800138000      添加转发目标（上限10个）
AT+FWD=SMS,DEL,13800138000      删除转发目标
AT+FWD=SMS,ON                   开启
```

#### 钉钉（群机器人 Webhook）

```
AT+FWD=DING,SET,<webhook地址>[,加签密钥]
AT+FWD=DING,SET,https://oapi.dingtalk.com/robot/send?access_token=xxx,SECxxxxx
```

- webhook 地址：钉钉群 → 群设置 → 机器人 → 添加"自定义"机器人；
- 加签密钥：机器人安全设置选择"加签"时生成（SEC 开头）；
  若机器人用"自定义关键词"安全设置，密钥省略即可（建议关键词填"短信"）。

#### 飞书（群机器人 Webhook）

```
AT+FWD=FS,SET,<webhook地址>[,签名密钥]
AT+FWD=FS,SET,https://open.feishu.cn/open-apis/bot/v2/hook/xxx,xxxxx
```

- webhook 地址：飞书群 → 设置 → 群机器人 → 添加"自定义机器人"；
- 签名密钥：机器人安全设置选择"签名校验"时填写，未开启签名校验则省略。

#### Server酱（微信推送）

```
AT+FWD=SC,SET,<SendKey或完整URL>
AT+FWD=SC,SET,SCTxxxxxxxx            （Server酱 Turbo SendKey）
AT+FWD=SC,SET,https://.../send/xxx.send   （Server酱³/自建兼容服务的完整URL）
```

SendKey 在 [sct.ftqq.com](https://sct.ftqq.com/) 登录后获取。

#### SET 成功即开启

所有通道 `SET` 成功后自动开启（应答会说明）；也可用 `ON`/`OFF` 随时切换。
未配置完整时 `ON` 会报错。

### AT+RESET —— 恢复出厂设置

```
AT+RESET
```

清空全部配置（白名单/密码/通道/初始化状态），固件回到未初始化状态。
需要重新执行 `AT+INIT`。

### AT+REBOOT —— 重启模块

应答 OK 后约 3 秒重启。

## 转发内容格式

- **短信通道**（紧凑，省条数）：

  ```
  【SmsPigeon】来自 10086:
  尊敬的用户：您的账户余额……
  ```

- **网络通道**（含时间戳）：

  ```
  【SmsPigeon】收到来自 10086 的短信
  时间: 2026-09-11 12:00:00

  尊敬的用户：您的账户余额……
  ```

## 自动复位（防捡漏）

以下情形固件会**自动恢复出厂设置**，回到未初始化状态：

1. **SIM 卡变更**：插入与上次绑定不同的 SIM 卡（首次插卡即绑定，
   与是否初始化无关）；
2. **连续第 3 次无卡开机**：开机 15 秒内未检测到 SIM 卡即计 1 次，
   计数持久保存，检测到卡即清零，累计 3 次触发复位。

复位后需要重新 `AT+INIT` 初始化。若发现命令突然全部无响应，
先确认 SIM 卡是否换过或脱离过设备。

## 锁死自救

- 白名单开启时删空被拒绝，正常配置不会锁死；
- 若关闭白名单+清空密码后又删错白名单等极端操作导致无法控制：
  拔卡连续开关机 3 次触发自动复位，或用 Luatools 重烧固件。

## 安全说明

- 命令应答只回给命令发送者本人；
- 未授权命令静默丢弃，不向探测者暴露设备存在性；
- IMEI 是初始配置的鉴权依据——能物理接触模块的人可从丝印读到
  IMEI。若设备部署在不可信物理环境，收到 `AT+INIT` 成功应答
  而自己没发过时，说明设备已被物理接触；
- 密码、白名单仅存储在模块 fskv 分区，不经过任何第三方服务器
  （钉钉/飞书/Server酱的 webhook 是你自己配置的接收端）。
