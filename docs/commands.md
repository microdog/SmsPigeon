# SmsPigeon 短信命令手册

SmsPigeon 的全部配置与控制均通过**中文句子命令**完成。
固件全程本地运行，不连接任何远程管理服务。

> **为什么是中文句子？** 运营商/物联网卡平台会过滤机器特征短信（实测
> `鸽+FWD=SMS,ADD,号码` 被拦、纯文本可达），中文自然句式可通过过滤。
> 此前的 AT 风格格式（`鸽+`/`AT+`）已完全移除。

## 命令语法

所有命令以 **`信鸽`** 开头，用逗号引出参数：

```
信鸽                      ← 链路探测（收到 OK:SmsPigeon 表示鉴权通过）
信鸽，状态
信鸽，初始化，<模块IMEI>
信鸽，增加白名单，<号码>
```

规则：

- **前缀**：`信鸽` 后面跟逗号、顿号、空格、冒号均可（`信鸽，状态`、
  `信鸽 状态`、`信鸽：状态` 等效）；
- **全角自动归一**：中文输入法直接输入即可，`？＝＋，` 等全角符号、
  句尾的 `？；！` 都不算内容；
- **号码自由写法**：
  - 分组：`132-6257-5718`、`132 6257 5718`
  - 中文数字：`一三二六二五七五七一八`（支持幺=1、两=2、〇/零=0）
  - IMEI 同样支持以上写法；
- **防误触**：前缀后必须跟分隔符，`信鸽子汤很好喝` 这类正常短信
  不会被误判为命令（会被正常转发）；
- 任何以 `信鸽` 开头的短信都按命令处理：短语未识别会收到
  `未知命令` 应答（鉴权通过时），不会转发。

## 密码模式

设置密码后，`信鸽` 前缀替换为密码，默认前缀立即失效：

```
8888，状态          （密码为 8888 时）
蓝色风筝，状态       （密码支持中文）
8888                （链路探测）
```

密码要求：4-16 个字符（中文算 1 个）、不含逗号/空格、不可为 `信鸽`。
用默认前缀发不出合法命令的短信一律按普通短信转发。

## 鉴权模型

固件有三道独立门禁，**已启用的门禁必须全部通过**：

1. **初始化门禁**：未初始化的固件只接受 `信鸽，初始化`，其余一律
   静默丢弃（不回复、不转发）；
2. **白名单门禁**：白名单开启时，发送者号码必须在白名单内；
3. **密码门禁**：设置密码后，命令必须以密码开头（见上节）。

白名单与密码相互独立：

| 白名单 | 密码 | 效果 |
|---|---|---|
| 开 | 未设 | 仅白名单号码可控制 |
| 开 | 已设 | 白名单号码 + 密码前缀，两者都要满足 |
| 关 | 已设 | 任何知道密码的人可控制 |
| 关 | 未设 | **任何命令短信均可控制本机（危险）** |

号码匹配自动归一化：`+8613800138000`、`13800138000`、
`一三八零零一三八零零零` 视为同一号码。

被拒绝的命令（未初始化、未授权）不会收到任何回复，防止探测。

## 命令总览

发送 `信鸽，帮助` 可随时获取命令列表。

### 初始化（唯一免鉴权命令）

```
信鸽，初始化，<模块IMEI>
```

- 仅未初始化状态可用，IMEI 必须与模块实际 IMEI 一致（数字串比对，
  支持中文数字/分组写法）；
- 发送者号码自动加入白名单；
- 已初始化的固件再次收到初始化命令只回笼统 `ERROR`（不区分 IMEI 错误
  还是已初始化，避免泄露状态）。

模块 IMEI 可从模块丝印/包装查询，也可在 Luatools 日志 `self_info` 行查看。

### 状态与信息

| 命令 | 说明 |
|---|---|
| `信鸽` | 链路探测，回复 `OK:SmsPigeon` |
| `信鸽，状态`（或 查询状态/查看状态） | 状态总览 |
| `信鸽，版本` | 固件版本 |
| `信鸽，调试，开/关` | 内核短信调试日志（PDU 级含正文，默认关、重启复位，排障用） |
| `信鸽，统计` | 运行统计：累计转发/失败/丢弃/过滤/待发（见「运行统计与失败重发」） |
| `信鸽，清零统计` | 统计归零（不影响待发队列与暂存） |
| `信鸽，帮助`（或 命令列表） | 命令列表 |

状态应答示例：

### 白名单管理

| 命令 | 说明 |
|---|---|
| `信鸽，白名单` | 查看白名单 |
| `信鸽，增加白名单，<号码>`（或 添加） | 添加（上限 10 个） |
| `信鸽，删除白名单，<号码>`（或 移除） | 删除 |
| `信鸽，开启白名单` / `信鸽，关闭白名单` | 开关 |

安全约束：

- 白名单开启时**不可删空**（最后一个号码删不掉，防止把自己锁死），
  需先 `信鸽，关闭白名单`；
- 关闭白名单且未设密码时，应答会附带风险警告。

### 密码管理

| 命令 | 说明 |
|---|---|
| `信鸽，设置密码，<新密码>` | 设置（4-16 字符，支持中文） |
| `信鸽，清除密码`（或 清空密码） | 清除，恢复 `信鸽` 前缀 |

修改密码时用**旧密码**作前缀（如旧密码 8888：`8888，设置密码，6666`）。
密码仅保存在模块本地。

### 转发通道管理

`信鸽，转发` 查看所有通道状态。

通道名：`短信`、`钉钉`、`飞书`、`Server酱`、`企业微信`。

通用操作（`<通道>` 直接跟在动词后或用逗号隔开均可）：

| 命令 | 说明 |
|---|---|
| `信鸽，开启<通道>` | 开启（未配置时报错） |
| `信鸽，关闭<通道>` | 关闭 |
| `信鸽，清空<通道>` | 清空该通道配置 |

#### 短信通道（离线可用）

```
信鸽，增加转发号码，13262575718        添加转发目标（上限10个）
信鸽，删除转发号码，13262575718        删除转发目标
信鸽，开启短信转发
```

也支持 `增加短信转发号码` 等更长说法。

#### 钉钉（群机器人 Webhook）

```
信鸽，设置钉钉，<webhook或token>[，<加签密钥>]
信鸽，设置钉钉，03f4753e…a97855f4d，SECxxxxx      ← 纯 token 形式（推荐）
信鸽，设置钉钉，https://oapi.dingtalk.com/robot/send?access_token=xxx，SECxxxxx
```

- 机器人创建：钉钉群 → 群设置 → 机器人 → 添加"自定义"机器人；
- 加签密钥：机器人安全设置选"加签"时生成（SEC 开头）；用"自定义关键词"
  安全设置时省略密钥（建议关键词填"短信"）。
- **纯 token 形式**：webhook 完整 URL 带 `http://`、`access_token=` 等
  特征，可能被运营商内容过滤拦截；token 取 webhook 地址中
  `access_token=` 后面的那串字符，只含字母数字，固件自动拼出标准地址。

#### 飞书（群机器人 Webhook）

```
信鸽，设置飞书，<webhook或hook id>[，<签名密钥>]
信鸽，设置飞书，bb089165-4b73-4f80-9ed0-da0c908b44e5      ← 纯 hook id 形式（推荐）
信鸽，设置飞书，https://open.feishu.cn/open-apis/bot/v2/hook/xxx，xxxxx
```

- 机器人创建：飞书群 → 设置 → 群机器人 → 添加"自定义机器人"；
- 签名密钥：机器人安全设置选"签名校验"时填写，未开启则省略；
- **纯 hook id 形式**：取 webhook 地址最后一段（`/hook/` 后面的部分，
  如 `bb089165-4b73-4f80-9ed0-da0c908b44e5`），规避 URL 过滤，
  固件自动拼出标准地址。

#### Server酱

```
信鸽，设置Server酱，<SendKey或完整URL>
信鸽，设置Server酱，SCTxxxxxxxx
信鸽，设置Server酱，https://.../send/xxx.send
```

SendKey 在 [sct.ftqq.com](https://sct.ftqq.com/) 登录后获取；完整 URL
形式适用于 Server酱³ 或自建兼容服务。

#### 企业微信（消息推送，原"群机器人"）

```
信鸽，设置企业微信，<key或webhook地址>
信鸽，设置企业微信，693a91f6-7aoc-4bc4-97a0-0ec2sifa5aaa      ← 纯 key 形式（推荐）
信鸽，设置企业微信，https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx
```

- 机器人创建：企业微信群 → 群设置 → 添加"消息推送"（原"群机器人"）；
- **纯 key 形式**：key 为 webhook 地址中 `key=` 参数的值（UUID 形式），
  规避 URL 特征被运营商过滤，固件自动拼出标准地址；
- 接口文档：[消息推送配置说明](https://developer.work.weixin.qq.com/document/path/99110)。

#### 设置成功即开启

所有通道**设置**成功后自动开启（应答会说明），也可随时 开启/关闭/清空。

### 来电提醒

收到来电时，固件向**全部已启用的转发目标**推送来电提醒（含来电号码；
固件不接听、不挂断，只做事件监听）。同一通电话多次响铃只提醒一次。

| 命令 | 说明 |
|---|---|
| `信鸽，来电提醒` | 查看开关状态 |
| `信鸽，开启来电提醒` | 开启（默认开） |
| `信鸽，关闭来电提醒` | 关闭 |

- 提醒文案：短信通道为 `来电:<号码>`，网络通道为 `来电提醒:号码 <号码>`，
  均携带转发前缀/设备标识（与短信转发一致）；
- 与短信转发共用队列与限速（队列上限 20、2 秒间隔）；
- 多数物联网卡未开通语音，收不到任何来电，本功能不触发；
- 想接到来电请配合手机侧呼叫转移（`**61*` 未接通转移两全其美，
  详见 README FAQ）。

### 心跳报平安

按设定间隔向**全部已启用的转发目标**推送一条在线心跳，附信号强度与
转发统计摘要。解决无人值守部署的"静默死亡"：设备断网/死机没有心跳，
你第一时间就知道。

| 命令 | 说明 |
|---|---|
| `信鸽，设置心跳，<小时>` | 设置间隔并开启（1-168 整数，只认阿拉伯数字；间隔是数量，中文数字逐位读法会错值，如 `二十`→2） |
| `信鸽，心跳` | 查看当前间隔 |
| `信鸽，关闭心跳` | 关闭（默认关） |

- 心跳与转发走同一队列与通道：**纯网络通道（钉钉/飞书等）免费**，
  短信通道启用时按间隔计话费（24 小时一次≈每天 1 条短信）；
- 心跳文案示例（短信通道）：`在线
信号:25
累计转发:12 失败:0 丢弃:0 过滤:2
待发:0`；
- 只在已初始化时布防；重启后按已存配置自动恢复布防；
- 恢复出厂/换卡复位后回到默认关。

### 转发过滤

命中规则的短信**静默丢弃**（不转发、不回复、计数可查），用于挡运营商
营销短信与骚扰号码，省转发话费。**只作用于转发路径**：被拉黑号码发来
的命令仍走白名单/密码鉴权，不受影响。

黑名单（按发件人号码，归一化匹配）：

| 命令 | 说明 |
|---|---|
| `信鸽，拉黑，<号码>` | 加入黑名单（上限 10 个） |
| `信鸽，取消拉黑，<号码>` | 移出黑名单 |
| `信鸽，拉黑列表` | 查看黑名单 |

过滤词（按正文包含匹配，可批量添加/删除）：

| 命令 | 说明 |
|---|---|
| `信鸽，添加过滤词，<词>[，<词>...]` | 批量添加（每词 1-10 字，上限 10 个） |
| `信鸽，删除过滤词，<词>[，<词>...]` | 批量删除 |
| `信鸽，过滤词` | 查看过滤词列表 |

- 丢弃量在 `信鸽，统计` 的 `过滤` 一行可查（丢弃原因看日志
  `发件人已拉黑,丢弃短信` / `正文命中过滤词,丢弃短信`）；
- 默认两表皆空 = 全量转发；
- 黑名单与命令白名单是两回事：拉黑人仍可尝试命令，但不在白名单
  就过不了鉴权。

### 验证码提取

正文含 验证码/校验码/动态码/授权码/认证码/取件码 等触发词时，转发
文案**首行**附加 `[验证码:xxxx]`（取正文首个独立的 4-8 位数字串，
跳过 11 位手机号/长单号），手机通知栏预览直接看到验证码。

| 命令 | 说明 |
|---|---|
| `信鸽，验证码` | 查看开关状态 |
| `信鸽，开启验证码` | 开启（默认开） |
| `信鸽，关闭验证码` | 关闭 |

短信通道效果（通知栏第一行即 `[验证码:4527] 来自 10086:`）；
网络通道同理置于文案首部。无触发词或提取不到时不附加任何行，
日期/账单类数字不会误报。

### 运行统计与失败重发

| 命令 | 说明 |
|---|---|
| `信鸽，统计` | 累计转发/失败/丢弃/过滤/待发（重启后清零） |
| `信鸽，清零统计` | 归零 |
| `信鸽，重发` | 手动重发暂存消息（无暂存回 `无暂存消息`） |

- **统计口径**：`累计转发` = 至少一个通道成功的事件数；`失败` =
  有通道被尝试但全部失败；`丢弃` = 队列溢出丢最旧；`过滤` = 命中
  黑名单/过滤词；
- **失败暂存**：全部通道失败的转发自动暂存（最多 5 条，护闪存寿命），
  网络恢复（IP_READY）时自动重新入队；重试一次仍失败则永久丢弃，
  不会往复打环；暂存随恢复出厂清除（上一任机主的内容不得外泄）；
- **断网自愈**（无命令）：连续 30 分钟无网络注册自动重启模组，
  4G 假死场景免人工断电；重启后计数从零开始。

### 远程发短信

控制本机（模块内的 SIM 卡）向指定号码发送一条短信：

| 命令 | 说明 |
|---|---|
| `信鸽，发送短信，<号码>，<内容>` | 号码支持中文数字（如 `一三八〇〇一三八〇〇〇`） |

- 内容为号码之后的全部文本，**逗号按原样保留**；
- 号码须 5-11 位（可用 `10086` 等短号码）；
- 应答 `OK:已提交发送,收件:<号码>`——`sms.send` 的同步返回仅表示
  发送任务已提交，真实结果由 SMS_SENT 事件携带（可在日志观察）；
- 与所有命令相同，受初始化/白名单/密码三重门禁保护。

### 配置导出与导入

| 命令 | 说明 |
|---|---|
| `信鸽，导出配置` | 全部配置导出为一条短信（可原样转发给新设备导入） |
| `信鸽，导入配置` | 首行之后每行一条命令，批量执行（合并语义） |

导出内容是"命令回放"：首行即 `信鸽，导入配置`，其后每行一条普通命令，
末行 `#` 注释携带版本与条数。换机/灾备迁移四步：

1. 旧设备发送 `信鸽，导出配置`，收到导出短信；
2. SIM 卡移到新设备，向新设备发送 `信鸽，初始化，<新IMEI>`；
3. 把导出短信**原样转发**给新设备号码，收到 `OK:导入完成 成功N 跳过M`；
4. 需要密码模式时在新设备重新 `设置密码`。

导出示例（实际为一条长短信）：

```
信鸽，导入配置
开启白名单
增加白名单，13800138000
设置钉钉，03f4753e…a97855f4，SECxxxxx
增加转发号码，13262575718
拉黑，10699901
添加过滤词，发票，贷款
设置心跳，24
#SmsPigeon 1.3.0 共8条,密码不随导出,原样转发即可导入
```

- **合并语义**：导入不清空目标机现有配置，重复项按跳过计，重复导入
  幂等；要精确克隆先在目标机 `恢复出厂` + `初始化`；
- **密码不随导出**（导出内容会驻留手机收件箱，密码=完全控制权）；
  统计/失败暂存/防环标记/SIM 绑定等设备私有状态同样不导出；
- **安全**：导入短信与普通命令一样过三重门禁（整条鉴权一次，行内容
  不再逐条鉴权）；行内只执行允许清单中的配置命令——`初始化`/
  `恢复出厂`/`重启`/`发送短信`/`重发`/`导出`/`导入`自身及查询统计类
  一律拒绝（未来新增命令默认不可导入）；上限 50 行，失败行在汇总
  应答中列出；
- **防泄漏闸**：疑似导入内容（首行被手机加上"转发："等前缀、密码机上
  收到默认前缀的导出短信等命令解析失败的情形，或正文含 `#SmsPigeon`
  尾注）绝不进入转发通道——webhook token 与白名单不外泄；授权发送者
  会收到 `ERROR:导入格式错误` 提示，其余静默丢弃；
- 通道一律以纯 token/hook id/key 形式导出（规避出站 URL 特征被运营商
  内容过滤，重新导入时固件自动拼回标准地址）；
- 密码模式下的导入：包装行以密码开头（如 `8888，导入配置`），行内容
  仍为裸命令；行自带 `信鸽` 前缀亦可识别（手工粘贴容错）。

### 复位与重启

| 命令 | 说明 |
|---|---|
| `信鸽，恢复出厂` | 清空全部配置，回到未初始化 |
| `信鸽，重启` | 应答 OK 后约 3 秒重启 |

## 转发内容格式

转发消息**默认不携带任何标识前缀**（固定标识易被运营商当作特征过滤/拉黑），
可用下面的命令自定义前缀（含【】等样式自定）。
- **短信通道**（紧凑，省条数），默认无前缀：

  ```
  来自 10086:
  尊敬的用户：您的账户余额……
  ```

  验证码类短信首行会附加 `[验证码:4527]`（见「验证码提取」，可关）：
  ```
  [验证码:4527] 来自 10086:
  尊敬的用户：您的验证码是4527……
  ```

  末行会附加 8 位十六进制**防环标记**（每台设备随机生成，如
  `3f9a07c1`）：两台设备互加转发号码时防止无限互转烧话费，
  收到含本机标记的短信会被直接丢弃。标记为纯随机串、无固定词，
  不会被运营商识别为群发特征；请勿手工删除。

- **网络通道**（含时间戳），默认无前缀：

  ```
  收到来自 10086 的短信
  时间: 2026-09-11 12:00:00

  尊敬的用户：您的账户余额……
  ```

- 自定义前缀 `【短信鸽】` 后：

  ```
  【短信鸽】来自 10086:
  尊敬的用户：您的账户余额……
  ```

- 携带设备标识时（见下节），首行追加 `[设备:xxx]`：

  ```
  来自 10086 [设备:1234]:
  尊敬的用户：您的账户余额……
  ```

### 转发前缀

| 命令 | 说明 |
|---|---|
| `信鸽，前缀` | 查看当前前缀 |
| `信鸽，设置前缀，<前缀文本>` | 设置（上限 30 字符，逗号可包含；不可为"信鸽"等命令形式） |
| `信鸽，清除前缀` | 清除（恢复默认无前缀） |

Server酱的推送标题同样使用该前缀。`信鸽，状态` 可查看当前前缀。

### 设备标识（identity）

多个设备转发到同一个群时，用于区分消息来自哪台设备：

| 命令 | 说明 |
|---|---|
| `信鸽，标识` | 查看当前标识与模式 |
| `信鸽，设置标识，<标识文本>` | 自定义标识（上限 16 字符，逗号可包含） |
| `信鸽，关闭标识` | 转发不携带标识 |
| `信鸽，清除标识` | 恢复自动模式 |

**自动模式（默认）**：固件尝试读取 SIM 卡本机号码（MSISDN），取尾 4 位
作为标识；取不到（物联网卡常不写号码）则不携带。标识渲染为首行追加
`[设备:xxx]`，Server酱标题同步携带。`信鸽，状态` 可查看当前标识。

## 自动复位（防捡漏）

以下情形固件会**自动恢复出厂设置**，回到未初始化状态：

1. **SIM 卡变更**：插入与上次绑定不同的 SIM 卡（首次插卡即绑定）；
2. **连续第 3 次无卡开机**：开机 15 秒内无 SIM 计 1 次，累计 3 次触发。

复位后需要重新 `信鸽，初始化`。若命令突然全部无响应，先确认 SIM 卡
是否换过或脱离过设备。

## 锁死自救

- 白名单开启时删空被拒绝，正常配置不会锁死；
- 极端情况无法控制时：拔卡连续开关机 3 次触发自动复位，或重烧固件。

## 从旧版本升级

- 用旧版 `鸽+`/`AT+` 命令初始化过的设备：配置（初始化状态/白名单/
  密码/通道）全部保留，改发中文命令即可；
- 旧命令格式（`鸽+ST?`、`AT+ST?`）不再识别，按普通短信转发。

## 安全说明

- 命令应答只回给命令发送者本人；
- 未授权命令静默丢弃，不向探测者暴露设备存在性；
- IMEI 是初始配置的鉴权依据——能物理接触模块的人可从丝印读到 IMEI。
  若设备部署在不可信物理环境，收到自己没发过的 `初始化成功` 应答
  说明设备已被物理接触；
- 密码、白名单仅存储在模块 fskv 分区，不经过任何第三方服务器
  （钉钉/飞书/Server酱的 webhook 是你自己配置的接收端）。
