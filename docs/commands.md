# SmsPigeon 短信命令手册

SmsPigeon 的全部配置与控制均通过**中文句子命令**完成。
固件全程本地运行，不连接任何远程管理服务。

> **为什么是中文句子？** 运营商/物联网卡平台会过滤机器特征短信（实测
> `鸽+FWD=SMS,ADD,号码` 被拦、纯文本可达），中文自然句式可通过过滤。
> 此前的 AT 风格格式（`鸽+`/`AT+`）已完全移除。

## 命令语法

所有命令以 **`信鸽`** 开头，用逗号引出参数：

```
信鸽                      ← 链路探测（收到 OK:SmsPigeon 表示鉴权通过）
信鸽，状态
信鸽，初始化，<模块IMEI>
信鸽，增加白名单，<号码>
```

规则：

- **前缀**：`信鸽` 后面跟逗号、顿号、空格、冒号均可（`信鸽，状态`、
  `信鸽 状态`、`信鸽：状态` 等效）；
- **全角自动归一**：中文输入法直接输入即可，`？＝＋，` 等全角符号、
  句尾的 `？；！` 都不算内容；
- **号码自由写法**：
  - 分组：`132-6257-5718`、`132 6257 5718`
  - 中文数字：`一三二六二五七五七一八`（支持幺=1、两=2、〇/零=0）
  - IMEI 同样支持以上写法；
- **防误触**：前缀后必须跟分隔符，`信鸽子汤很好喝` 这类正常短信
  不会被误判为命令（会被正常转发）；
- 任何以 `信鸽` 开头的短信都按命令处理：短语未识别会收到
  `未知命令` 应答（鉴权通过时），不会转发。

## 密码模式

设置密码后，`信鸽` 前缀替换为密码，默认前缀立即失效：

```
8888，状态          （密码为 8888 时）
蓝色风筝，状态       （密码支持中文）
8888                （链路探测）
```

密码要求：4-16 个字符（中文算 1 个）、不含逗号/空格、不可为 `信鸽`。
用默认前缀发不出合法命令的短信一律按普通短信转发。

## 鉴权模型

固件有三道独立门禁，**已启用的门禁必须全部通过**：

1. **初始化门禁**：未初始化的固件只接受 `信鸽，初始化`，其余一律
   静默丢弃（不回复、不转发）；
2. **白名单门禁**：白名单开启时，发送者号码必须在白名单内；
3. **密码门禁**：设置密码后，命令必须以密码开头（见上节）。

白名单与密码相互独立：

| 白名单 | 密码 | 效果 |
|---|---|---|
| 开 | 未设 | 仅白名单号码可控制 |
| 开 | 已设 | 白名单号码 + 密码前缀，两者都要满足 |
| 关 | 已设 | 任何知道密码的人可控制 |
| 关 | 未设 | **任何命令短信均可控制本机（危险）** |

号码匹配自动归一化：`+8613800138000`、`13800138000`、
`一三八零零一三八零零零` 视为同一号码。

被拒绝的命令（未初始化、未授权）不会收到任何回复，防止探测。

## 命令总览

发送 `信鸽，帮助` 可随时获取命令列表。

### 初始化（唯一免鉴权命令）

```
信鸽，初始化，<模块IMEI>
```

- 仅未初始化状态可用，IMEI 必须与模块实际 IMEI 一致（数字串比对，
  支持中文数字/分组写法）；
- 发送者号码自动加入白名单；
- 已初始化的固件再次收到初始化命令只回笼统 `ERROR`（不区分 IMEI 错误
  还是已初始化，避免泄露状态）。

模块 IMEI 可从模块丝印/包装查询，也可在 Luatools 日志 `self_info` 行查看。

### 状态与信息

| 命令 | 说明 |
|---|---|
| `信鸽` | 链路探测，回复 `OK:SmsPigeon` |
| `信鸽，状态`（或 查询状态/查看状态） | 状态总览 |
| `信鸽，版本` | 固件版本 |
| `信鸽，帮助`（或 命令列表） | 命令列表 |

状态应答示例：

```
OK:
版本:SmsPigeon 1.0.0
模块:Air780EHV
IMEI:86xxxxxxxxxxxxx
ICCID:8986xxxxxxxxxxxxxxxx
信号:25
白名单:开(2个)
密码:未设置
通道:
 短信:开(1个目标)
 钉钉:开
 飞书:未配置
 微信推送:未配置
```

### 白名单管理

| 命令 | 说明 |
|---|---|
| `信鸽，白名单` | 查看白名单 |
| `信鸽，增加白名单，<号码>`（或 添加） | 添加（上限 10 个） |
| `信鸽，删除白名单，<号码>`（或 移除） | 删除 |
| `信鸽，开启白名单` / `信鸽，关闭白名单` | 开关 |

安全约束：

- 白名单开启时**不可删空**（最后一个号码删不掉，防止把自己锁死），
  需先 `信鸽，关闭白名单`；
- 关闭白名单且未设密码时，应答会附带风险警告。

### 密码管理

| 命令 | 说明 |
|---|---|
| `信鸽，设置密码，<新密码>` | 设置（4-16 字符，支持中文） |
| `信鸽，清除密码`（或 清空密码） | 清除，恢复 `信鸽` 前缀 |

修改密码时用**旧密码**作前缀（如旧密码 8888：`8888，设置密码，6666`）。
密码仅保存在模块本地。

### 转发通道管理

`信鸽，转发` 查看所有通道状态。

通道名：`短信`、`钉钉`、`飞书`、`微信推送`。

通用操作（`<通道>` 直接跟在动词后或用逗号隔开均可）：

| 命令 | 说明 |
|---|---|
| `信鸽，开启<通道>` | 开启（未配置时报错） |
| `信鸽，关闭<通道>` | 关闭 |
| `信鸽，清空<通道>` | 清空该通道配置 |

#### 短信通道（离线可用）

```
信鸽，增加转发号码，13262575718        添加转发目标（上限10个）
信鸽，删除转发号码，13262575718        删除转发目标
信鸽，开启短信转发
```

也支持 `增加短信转发号码` 等更长说法。

#### 钉钉（群机器人 Webhook）

```
信鸽，设置钉钉，<webhook地址>[，<加签密钥>]
信鸽，设置钉钉，https://oapi.dingtalk.com/robot/send?access_token=xxx，SECxxxxx
```

- webhook：钉钉群 → 群设置 → 机器人 → 添加"自定义"机器人；
- 加签密钥：机器人安全设置选"加签"时生成（SEC 开头）；用"自定义关键词"
  安全设置时省略密钥（建议关键词填"短信"）。

#### 飞书（群机器人 Webhook）

```
信鸽，设置飞书，<webhook地址>[，<签名密钥>]
信鸽，设置飞书，https://open.feishu.cn/open-apis/bot/v2/hook/xxx，xxxxx
```

#### 微信推送（Server酱）

```
信鸽，设置微信推送，<SendKey或完整URL>
信鸽，设置微信推送，SCTxxxxxxxx
信鸽，设置微信推送，https://.../send/xxx.send
```

SendKey 在 [sct.ftqq.com](https://sct.ftqq.com/) 登录后获取；完整 URL
形式适用于 Server酱³ 或自建兼容服务。

#### 设置成功即开启

所有通道**设置**成功后自动开启（应答会说明），也可随时 开启/关闭/清空。

### 复位与重启

| 命令 | 说明 |
|---|---|
| `信鸽，恢复出厂` | 清空全部配置，回到未初始化 |
| `信鸽，重启` | 应答 OK 后约 3 秒重启 |

## 转发内容格式

- **短信通道**（紧凑，省条数）：

  ```
  【SmsPigeon】来自 10086:
  尊敬的用户：您的账户余额……
  ```

- **网络通道**（含时间戳）：

  ```
  【SmsPigeon】收到来自 10086 的短信
  时间: 2026-09-11 12:00:00

  尊敬的用户：您的账户余额……
  ```

## 自动复位（防捡漏）

以下情形固件会**自动恢复出厂设置**，回到未初始化状态：

1. **SIM 卡变更**：插入与上次绑定不同的 SIM 卡（首次插卡即绑定）；
2. **连续第 3 次无卡开机**：开机 15 秒内无 SIM 计 1 次，累计 3 次触发。

复位后需要重新 `信鸽，初始化`。若命令突然全部无响应，先确认 SIM 卡
是否换过或脱离过设备。

## 锁死自救

- 白名单开启时删空被拒绝，正常配置不会锁死；
- 极端情况无法控制时：拔卡连续开关机 3 次触发自动复位，或重烧固件。

## 从旧版本升级

- 用旧版 `鸽+`/`AT+` 命令初始化过的设备：配置（初始化状态/白名单/
  密码/通道）全部保留，改发中文命令即可；
- 旧命令格式（`鸽+ST?`、`AT+ST?`）不再识别，按普通短信转发。

## 安全说明

- 命令应答只回给命令发送者本人；
- 未授权命令静默丢弃，不向探测者暴露设备存在性；
- IMEI 是初始配置的鉴权依据——能物理接触模块的人可从丝印读到 IMEI。
  若设备部署在不可信物理环境，收到自己没发过的 `初始化成功` 应答
  说明设备已被物理接触；
- 密码、白名单仅存储在模块 fskv 分区，不经过任何第三方服务器
  （钉钉/飞书/Server酱的 webhook 是你自己配置的接收端）。
